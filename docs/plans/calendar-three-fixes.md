# 日历聊天三处修复

确认卡片仍是写入关口。不解析用户句子里的钟点，也不做双向同步。

## 1. 改期保留时长和备注

用户只改开始时间时，模型仍可能填上 1 小时的 `end_at`，并把「带上大纲」收成「大纲」。抽槽增加 `change_end` / `change_notes`。缺省、空、false 都表示不改；只有明确为 true 才采用模型的结束时间和备注。对上的那条日程因此保留原来的时长和备注。

## 2. 撤销用 Google id

预填对上唯一一条 Google 日程时，把它的 id 放进卡片 `external_id`。确认改期或撤销优先用这个 id；没有 id 时仍按标题精确匹配。对不上返回 409，不写。前端确认时带上 `external_id`。

## 3. 空档说明不把忙时说成有空

挑空档的提示写明：列表里已占用的时间不能说成有空；拿不准就让用户看列表。重叠过滤丢掉时段后，若说明仍在声称有空，改成一句短的安全说明。建议几段空档、以及「找空档 / 约个会」出创建卡，都不在这次范围里。
