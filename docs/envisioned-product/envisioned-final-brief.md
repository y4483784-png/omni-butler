## 产品形态（已锁定）

- 主形态：一个桌面安装包 = 完整产品。聊天窗和本机动手在同一应用里。
- 网页版保留，但是瘦功能：对话、日历确认卡、知识库等；没有本机动手。
- 邮件是一等入口，来信也可当事件。不做人与产品的外接聊天总机（微信 / Telegram / Slack 等）。
- 不做手机端，不做云手机 / 在 App 里点击自动化。看屏点点点式桌面视觉操控后置，不进本版主链。
- 办事：优先连接器 / API；没有则用服务器上的受控浏览器做搜、加购、填表、结账。登录、付款、发消息走确认或保险柜。遇到只有 App 里才有的墙，停下来告诉人。
- 「上网」是白名单里的一项能力：只开 DeepSeek 模型自带联网，同一轮不另走已废弃的智谱搜索工具。
- 写法：在现有 Omni-Butler 上演进，不整仓换底座、不推倒重写。

## 主链（①–⑪）

1. 入口：桌面完整包 / 瘦网页 / 邮件。
2. 外壳（要做，简化）：登录与身份；拼上下文（长记忆 + 会话）；边生成边推气泡；人可随时插话或叫停，干活可暂停或改方向。停止要传到子任务、队列、以及真实请求发出前，不是只停文字流。按入口略调说法，先不做完整按信道输出规范。确认闸不归外壳管。
3. 事件驱动主动（要做）：来源 → 程序规则过滤 → 模型判断要不要动。已有对应任务则订阅直通干活，否则交给派活开新任务。中间要有事件收件箱和持久回执，按来源与投递编号去重。回执分清：已接收 / 已派活 / 外部成功。收到事件不等于外部动作成功。写操作仍走确认闸。先不做投机执行。
4. 派活只编排：观察来意，分派本轮任务。派活自己不调工具、不出确认卡。
5. 任务与授权：任务包带本轮代次。共享状态为 `running`、`waiting_person`、`waiting_resource`、`completed`、`stopped`。正常做完是 `completed`。`stopped` 只表示人主动停掉，或看门狗安全停掉。不要把正常做完标成 `stopped`。停止后旧代结果不能复活。授权叠三层：身份 → 工具白名单 → 本轮允许。上下文变长不抬权。
6. 干活内核：规划 → 还有下一步则按授权选能力，经确认闸和插头执行 → 看结果够不够，循环；没有下一步则写最终回复。
7. 确认闸嵌在干活里：会改世界的事先出确认卡，人看见并点了才继续。同一道闸覆盖日历新建改删、会前简报、会后跟进、办事登录/付款/发消息、本机动手前批准。同一件待办写按同一用户、同一动作、同一参数指纹只留一条和一张确认卡。代次只表示这一轮有没有被停掉，不作为「是不是同一件写」的键。执行前复验。改参数必须重批。已停止的那一轮不能再消费未用凭据。
8. 统一工具插头：干活只经此调用自有工具。工具可见不等于有执行权限，执行端独立验权。副作用契约分只读 / 幂等写 / 不可重放写；集中验权、取消检查、按契约重试。不可重放写若遇网络失败或结果未知，先核对是否已生效，不盲目重发。停止不等于撤销已发出的外部动作。本机动手插头仅桌面安装包内，且先过确认闸。
9. 少打扰、长记忆、主动脉搏（要做）：把握不够先记审计账本，不刷草稿卡；有结果或要人动手时才开口。长记忆是可查、可审计的偏好/要点档案，带变更账本（来源、修改者、前后值、待提交恢复、冲突时不强行撤销）。不默默抬权，也不做会乱改记忆的整套第二大脑。已经 `stopped` 的一轮不写长期记忆，也不为写记忆再问模型。到点提醒/催办经外壳推送，写操作仍走确认闸。
10. 看门狗（要做，简化）：主系统外的独立会话，定时查看是否有实质进展。等人、等资源不误判卡死。`completed` 不是卡住，不是失败，也不是取消。休眠不计超时。异常则提醒人或沿取消链安全停住。不自动改授权，不绕过确认闸，先不让看门狗改提示词或 Trigger 规则。
11. 背后服务：主服务、数据库、向量库、队列、文件、跑代码小服务、定时后台。定时后台不当助手核、不定确认闸。本机能力只存在于桌面安装包，与聊天同一应用。

## 明确不做 / 已废弃 / 后置（⑫）

整仓换底座；云手机点 App；无人确认自动写入或付钱；手机端；外接聊天总机；智谱网页搜索（改 DeepSeek 自带联网）；网页遥控独立本机助手；事件投机执行；看屏式桌面视觉操控（后置）；完整按信道输出规范 / 满分异步 ReAct（先用可打断简化版）；看门狗自行改提示词与 Trigger；用提示词恢复代替幂等账本；把隐藏工具当成授权或沙箱；把内存审批表当持久确认队列。
