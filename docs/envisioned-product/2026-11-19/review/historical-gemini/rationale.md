# 考虑并拒绝的方案清单（rationale）

下列设计选项在编制本方案时被明确评估并拒绝，每条给出唯一直接原因。

1. **合并 PR 93（`cursor/ev-net-responses-5880`）的 Pro Responses 内置联网方案**：已由 2026-11-19 定案替代，该方案会因搜索把普通回答升级为 `deepseek-v4-pro`，违背「Flash 回答 + DeepSeek 独立 Search/Fetch」且官方规定 Responses 内置 `web_search` 在 Flash 上会被忽略。
2. **用 Hermes 整仓替换或 fork 完整框架接管 Omni-Butler**：违背原地演进定案且会用 Hermes 单体会话循环覆盖 SuperAgent 持续交互派活与后台执行者的分层边界，同时引入不需要的多平台渠道与自动允许配置。
3. **将所有新消息默认收进 OpenCode 式单一串行队列或默认开启 `steer` 注入**：单队串行会阻塞独立新任务并行推进，而默认 `steer` 会在未确认时篡改正在执行的后台任务上下文，违背 SuperAgent 区分补充、修改、新任务、取消的四类交互定案。
4. **照搬 Hermes `session_authority.py`「最后订阅者离开后在空闲时关闭任务」的策略**：2026-11-19 已定案网页关闭或断网不得取消后台任务，客户端断连只能减少订阅者计数。
5. **用浏览器聊天原图先走智谱 `VISION_MODEL` 转文字再交给 Flash**：已核实 `deepseek-flash` 原生支持 Vision（`https://api-docs.deepseek.com/guides/vision.md`），先转文字会丢失视觉细节并违反聊天原图直传 Flash 与资料入库识图分路的定案。
6. **一次删除所有智谱依赖（连带移除嵌入、重排与资料入库 OCR）**：2026-11-19 定案只替换智谱网页搜索，保留嵌入、重排与入库识图，且未选定替代向量模型前更换嵌入会破坏 Qdrant 向量空间兼容性。
7. **在聊天界面新增常驻「联网开关」（地球按钮）或用脆弱关键词表硬路由全部用户消息**：已定案默认具备搜索能力且无常驻联网开关，「这次不要联网」作为该轮结构化约束下发给工具表和执行闸，而非全局开关或全量关键词正则路由器。
8. **仅隐藏前端「停止生成」按钮而保留后端 `begin_turn(stop_others=True)` 与 SSE 断连即 `task_run.stop`**：只藏按钮不改后端会让用户发补充消息或刷新网页时暗中杀掉后台任务，违背边做边聊与断线继续的核心要求。
9. **将重要写操作的确认闸前移到 SuperAgent 交互派活层，或按 OpenClaw/FullDots/OpenSuperBot/Rowboat 模式加入自动允许、始终允许、规则跳过**：确认闸必须留在后台执行层按真实参数指纹逐次单次消费，自动允许或派活层预放行会破坏最小授权与参数防篡改保证。
10. **沿用 `mail_entry.commit_send` 里的本地 `uuid4()` 伪造接受凭证或对已武装 `unknown` 邮件直接重试发送**：本地 UUID 不是邮件服务商接受证明，且网络超时后盲目重发会造成重复发信，必须改为真实传输接受凭据与未知先查策略。
11. **照搬 DS-Bot `mail_send` 的 `noDraftFor` 或收件人白名单跳过确认卡**：违反所有真实邮件发送必须经过人确认的强制规则。
12. **仅凭 `errand-compose` 返回 `outcome == "placed"` 而无关联号回声就判定下单成功，或在 `open.md` 关口未通过前静默安装 Browser Use**：当前 `errands.py:367-368` 允许空回声落单，存在跨单误对账风险；Browser Use 尚未实测 Flash 兼容与写前硬阻断，不能在计划阶段默默锁定依赖。
13. **继续使用单枚共享 `DESKTOP_PACKAGE_TOKEN` 或照搬 Open Super Agent 按设备名称字符串批删旧登记行**：共享令牌无法单台撤销，按名字批删会误撤销用户其他同名设备；必须按 OpenMausBot 模式单设备存 SHA-256 哈希并按 `device_id` 独立作废。
14. **引入新的数据库产品（如单独引入 MongoDB/SQLite 专库）或新增微服务来承载持久任务和看门狗状态**：现有 Postgres（含 RLS 与 Alembic）与 Redis/Celery 已完整承接记录系统与维护任务，新增数据库或微服务违背不换底座、最小变更原则。
15. **把看门狗超时秒数、各角色默认 `temperature`/`max_tokens` 或 DeepSeek 供应商取消接口写成确定值**：这些参数在当前定案与已打开官方文档中均无确定出处，编造数值会在后续实现中制造虚假契约，必须显式标为配置待定或未核实。
16. **将 `.env.example` 与 `config.py` 默认差异、32000 裁剪上限、最近十轮窗口、普通轮不回放思考列为严重缺陷并单开大重构单元**：已定案前者降级为顺手维护，后三者为合理现状策略。
17. **为了凑齐原 14 刀名字而把已完成的基础设施（`ev-task`/`ev-gate`/`ev-plug`/`ev-events`/`ev-memory`/`ev-webblock` 等）推倒重做，或把单刀强拆成无独立验收意义的碎片**：14 刀已在 `release` 上落地，新设计按真实依赖组织为 9 个可独立验证的演进单元，保留并扩展已有表结构与状态机。
