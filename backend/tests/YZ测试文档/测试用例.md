# 全能数字办公管家 Omni-Butler 使用指南

> 本文档为 Markdown 解析测试样例，演示标题、列表、表格、代码块与数学公式等常见语法。

## 1. 快速开始

1. 在左侧边栏点击 **新建会话**，输入自然语言即可开始对话。
2. 打开 **知识库** 面板，拖拽上传本地文档（支持 PDF / DOCX / XLSX / CSV / TXT / MD）。
3. 开启 **知识库问答** 模式，提问将基于你上传的文档并附带引用溯源。

## 2. 支持的文件格式

| 格式 | 用途 | 单文件上限 |
| :--- | :--- | :--- |
| .pdf | 白皮书、合同 | 20 MB |
| .docx | 纪要、报告 | 20 MB |
| .xlsx | 结构化表格 | 20 MB |
| .csv | 数据明细 | 20 MB |
| .txt | 纯文本制度 | 20 MB |
| .md | 文档笔记 | 20 MB |

> 单次最多批量上传 **5 个** 文件。

## 3. 数据分析示例

上传销售表后，可让 Agent 生成如下 Python 代码进行汇总：

```python
import pandas as pd

df = pd.read_excel("2026上半年销售业绩.xlsx", sheet_name="销售明细")
summary = df.groupby("大区")["利润(万元)"].sum()
print(summary)
```

当输出超过 15 行代码或生成图表时，系统会自动滑出**动态工作区**。

## 4. 常见问题

- **Q：知识库答非所问？** 请确认文件已解析完成（状态为"完成"），并开启知识库问答模式。
- **Q：公式如何显示？** 支持 LaTeX，例如行内 $E=mc^2$，或独立公式：

$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n
$$

- **Q：日程冲突怎么办？** Agent 会检测冲突并主动建议其他时间，你可在日程卡片上点击【修改】。
